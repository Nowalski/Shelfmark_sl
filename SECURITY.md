# Security

Please report a security issue privately through [GitHub Security Advisories](https://github.com/Nowalski/Shelfmark_sl/security/advisories/new). Avoid opening a public issue until the maintainer has had a chance to assess it.

Include the Shelfmark version, operating system, and safe steps to reproduce the problem. Do not attach Firestorm cache files, inventory exports, local database files, profile backups, personal photos, credentials, or unredacted logs. A short description is usually enough to start an investigation.
